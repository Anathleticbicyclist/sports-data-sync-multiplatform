第一章　这是什么软件？30 秒看懂

1.1 一句话定位

鸡翅幸哲迈进OB（开发体验版）是一款 Android 运动数据迁移工具，包名 com.jichi.ob.dev，核心理念是"让运动数据自由流动"。它能在二十余个运动平台之间自动同步运动记录（FIT/GPX 文件），让你在 A 平台的骑行/跑步数据，一键出现在 B、C、D 平台，不用手动导出再上传。

类比理解：它就像运动数据界的"万能转接头"。你的码表（iGPSPORT/迈金/百锐腾）、手表（佳明/高驰/松拓）、手机 App（Keep/行者/黑鸟）、室内骑行台（Wahoo/MyWhoosh/Zwift）产生的记录，都可以被它下载下来，自动转换成目标平台认识的格式，再上传过去。

1.2 它解决什么痛点

  • 多平台手动重复上传太累：以前换平台要手动导出 FIT/GPX 再上传，一次骑行要操作 5 个 App。
  • 国内区和国际区数据割裂：佳明中国和佳明国际是两套账号、两套数据；高驰中国和高驰国际也是。本软件直接互传。
  • 坐标偏移：迈金等国内码表用 GCJ-02（火星坐标），直接传到 Strava/佳明会偏移 400~500 米，赛段匹配不上。本软件自动纠偏。
  • 第三方 FIT 不被佳明识别：iGPSPORT/行者上传到佳明，Garmin Connect 不计算训练负荷。本软件自动伪装成 Edge 830 / Forerunner 945。
  • 智能手表数据进不了 Strava：华为/小米/OPPO/vivo 健康 App 本身不支持 Strava，但它们都能把数据汇到 Keep；本软件从 Keep 拉数据再分发。

  1. 开屏动画（SplashActivity）：浅蓝渐变 1 秒，显示"鸡翅幸哲迈进OB · 让运动数据自由流动"。
  2. 免责声明弹窗（dialog_disclaimer.xml）：首次启动弹出，需用户同意才能进入。
  3. 进入主界面（MainActivity）：底部四个 Tab——登录 / 同步设置 / 同步 / 关于。

第三章　五大主界面逐节点详解

本章按"这个按钮是什么 → 怎么点 → 背后发生了什么"的顺序，把 App 里每一个能点的节点都讲清楚。源码对应：SplashActivity、MainActivity、LoginFragment、SyncSettingsFragment、SyncFragment、AboutFragment、LoginWebActivity、LabLoginFragment、RecordCenterFragment。

3.1 开屏页 SplashActivity

  • 是什么：浅蓝渐变全屏，中央品牌 Logo + 标语。
  • 怎么来的：activity_splash.xml，1 秒延时后自动跳 MainActivity。
  • 背后做什么：初始化 PrefsManager（读深浅色模式三态）、WebBridge（迈金坐标转换引擎预热）、UpdateChecker（检查本地版本号）。

3.2 登录页 LoginFragment

登录页是用户接触最多的页面。顶部品牌横幅，中间是"一键登录检测"按钮 + "自动检查登录态"开关，下面是 Outbase 独立专区，再下面是已登录平台卡片网格，底部四个 Tab。

3.2.1 顶部"一键登录检测"按钮

  • 怎么用：点一下，App 会逐个探测所有已登录平台的 token 是否还有效。
  • 背后原理：对每个已登录平台发一个轻量请求（通常是拉 1 条活动列表），成功则保留，失败则标记为"需重新登录"。
  • 自动检查登录态开关：开启后每次启动 App 自动跑一遍上面的检测，不用手动点。

3.2.2 Outbase 独立专区

  • 怎么用：点 Outbase 卡片 → 手机号验证码登录（纯 API）。
  • 为什么单独放：Outbase 是聚合上传平台，几乎所有用户都会用它做最终目标，所以放显眼位置。

3.2.3 已登录平台卡片网格（每个卡片怎么点）

每个平台卡片显示：平台名称、品牌色小圆点（v7.7.7 起）、已下载条数、上传统计。点击卡片会弹出平台详情弹窗，里面有"重新登录""查看全部记录""注销"等按钮。

平台卡片点击后做什么登录方式背后原理
iGPSPORT（国内/国际） 弹出 WebView 登录页，输入账号密码后自动提取 token。v9.5.5 修复国际区 token 识别（从 IGS--TOKEN / persist:app-store / URL ?token= / 全 localStorage / cookie 多来源提取）。 WebView 加载 iGP 登录页，登录成功后 JS 注入读 localStorage，拿到 JWT 后真实校验（v7.6.0 起），无效自动清缓存重登。
行者 WebView 登录 imxingzhe.com。 官方开放 API，cookie 持久化。
迈金 / 顽鹿 WebView 登录 onelap.cn。 顽鹿 OTM API，refresh_token 自动续期（v7.5.9 起）。
黑鸟单车 WebView 登录 blackbirdsport.com。 v7.6.5 起导出标准 FIT（含累计 distance 字段）。
百锐腾 Bryton v9.5.5 起卡片标题带"· 国内站/国际站"，点击后弹窗可切换站点。国内站 brytonsports.cn，国际站 active.brytonsport.com。 DDP 协议（Meteor 三件套：X-User-Id / X-Auth-Token / x-api-key），仅下载 FIT，上传已移除。
佳明国际 v9.5.0 起改为 WebView 网页登录（支持两步验证 MFA）。登录成功后自动走 mobile SSO → OAuth1 preauthorized → OAuth2 exchange → DI Bearer token。 参考 garth 库，访问 connectapi.garmin.com 绕过 Cloudflare；403 自动刷新 CSRF token 重发（v9.5.1）。
佳明中国 同佳明国际，WebView 网页登录。 DI Token 直连 connectapi.garmin.cn（v7.9.0 起不再走 WebView 慢路径）。
高驰中国/国际 WebView 登录，抓取 CPL-coros-token。 中国区 OSS + fit/import；国际区 AWS S3。v7.6.4 起循环翻页拉全部活动（不再只限 200 条）。
Wahoo OAuth2 授权，自动模拟 SAML 登录流程，识别中文"授权"按钮。 v7.6.0 修复版起凭证自动复用/刷新，刷新后自动撤销旧令牌，不会累积超限。
Keep 弹窗输入手机号+密码，纯 API 登录（无 WebView）。 POST api.gotokeep.com/v1.1/users/login，拿 Bearer token；轨迹 AES-128-CBC 解密（密钥来自 running_page 开源项目）。
咕咚 Codoon 弹窗输入手机号+密码。 纯 API 三步登录（参考 running_page），仅下载，官方无上传接口。
Zepp（华米） 弹窗输入邮箱/手机号+密码。 纯 API 三步登录（参考 Mi-Fit-and-Zepp-workout-exporter），登录机会有限，请一次性输对。
Komoot 弹窗输入邮箱+密码。 官方内部 API（参考 Kompy），双向同步，WGS-84 坐标无需转换。
Suunto 松拓 实验室页 OAuth2，需自填 apizone 开发者凭证。 官方 Cloud API（参考 suunto-mcp），下载 FIT，GPX 自动转 FIT 上传。
MyWhoosh / Zwift 弹窗账号密码。 仅下载数据源；Zwift 需正式会员才有 FIT 下载权限。
Intervals.icu 粘贴个人 API Key。 官方开放 API，活动开始时间不早于 1971 年。
捷安特 弹窗账号密码。 纯 API 直传上传，不支持下载。
⚠️ 佳明登录特别提醒：佳明服务端对同一账号/设备/IP 短时间频繁登录（尤其失败尝试）会临时限流（HTTP 429）或触发人机验证，冷却期数小时到一天。请保证账号密码一次性输对；勿同时登录开发版与正式版；若提示风控请勿反复尝试，等冷却期过后再登录。若开启两步验证(MFA)，需先在佳明官网关闭（connect.garmin.com → 头像 → 账号设置 → 安全 → 两步验证 → 关闭）。

3.2.4 平台详情弹窗里的按钮

点任意已登录平台卡片，弹出详情弹窗，包含：

  • 重新登录：清空本地凭证，重新走登录流程。
  • 查看全部记录：进入记录中心（RecordCenterFragment），浏览该平台所有已下载的活动。v8.8.2 修复了从这里返回后底部导航不消失的 bug；v8.8.3 修复了关闭记录中心后错误跳到关于页的 bug。
  • 注销：清除 token/cookie/localStorage。v8.5.8 修复了 iGPSPORT 注销后仍自动登录旧账号的 bug（现在注销时无条件清 WebView cookie/localStorage）。

3.3 数据同步设置页 SyncSettingsFragment

这是"配置同步任务"的页面。所有控件从左到右、从上到下：

3.3.1 数据来源（单选）

  • 是什么：左侧四列网格，选一个平台作为"从哪下载"。
  • 怎么用：点一下即选中，选中后该卡片品牌色小圆点点亮。
  • 背后原理：对应 DataSource.sourcePlatforms() 列表。来源和目标不能是同一个平台。

3.3.2 同步目标（多选）

  • 是什么：右侧四列网格，可勾选多个平台。一条运动记录会自动分发到所有勾选目标。
  • 特殊标注：Keep 标注"半自动导入"；MyWhoosh/Zwift/咕咚/Zepp 标注"仅下载"（作为目标置灰）；百锐腾 v9.5.5 起作为目标置灰（上传开发中）。

3.3.3 同步数量滑块

  • 是什么：每次同步拉多少条活动。
  • 范围：1 ~ 50 条（高驰等已支持拉到 1000 条历史）。

3.3.4 跳过数量滑块

  • 是什么：跳过最近 N 条活动，用于增量同步。比如你已经同步到一周前，设跳过 7 就只同步更早的记录。

3.3.5 迈金坐标转换三开关

迈金 FIT 用 GCJ-02 火星坐标，直接传到 WGS-84 平台会偏移约 450 米。三个开关：

  • 七牛云 durl：建议关。这是迈金老的坐标转换通道，已被 fit_content 替代。

第四章　桥接专题

"桥接"是本软件最被用户关心的能力：让那些本身不支持 Strava 的平台（iGPSPORT、佳明、Wahoo、Keep、华为运动健康等）通过某条官方/半官方通道把数据送到 Strava；同时让那些数据只存在国内健康 App 里（华为/小米/OPPO/vivo 运动健康、Zepp 等）的智能手表记录，通过 Keep 这个中转拉出来再分发。

4.1 Strava 怎么进来？两条路

4.1.1 方案一：经 iGPSPORT / 佳明 / Wahoo 官方绑定 Strava（推荐，免费）

这是最简单、最稳定的方案，无需申请开发者 API，也不消耗你自己的开发者额度。

原理：iGPSPORT、佳明 Connect、Wahoo App 这三家官方都内置了"绑定 Strava 自动同步"功能。只要数据先进了这三家之一，它们会自动把活动推到 Strava，不需要本软件做任何 Strava 相关的事。

详细操作步骤（以佳明为例）

  1. 用本软件把运动记录同步到佳明中国或佳明国际（任选其一）。
  2. 手机或电脑浏览器登录 connect.garmin.cn（国内）或 connect.garmin.com（国际）。
  3. 点头像 → 设置 (Settings) → 账户关联 (Account Linking)。
  4. 在列表里找到 Strava，点 关联 (Link)。
  5. 跳转 Strava 授权页，登录 Strava 账号，点 Authorize。

  1. 本软件把数据同步到 iGPSPORT 国内版（iGPSPORT.com.cn）或国际版（iGPSPORT.com）。
  2. 打开 iGPSPORT App → 我的 → 设置 → 第三方分享 → Strava。
  3. 绑定你的 Strava 账号。之后 iGP 上的每条新活动自动同步到 Strava。
  4. 注意：iGPSPORT 国内版和国际版是两套独立账号，Strava 绑定也各绑各的。如果你用国际版，绑 strava.com；国内版绑 strava.cn 或 strava.com（看你 Strava 账号注册地）。

Wahoo 桥接 Strava

  1. 本软件把数据同步到 Wahoo（需 OAuth2 登录，见 3.2.3）。
  2. 打开 Wahoo App → Settings → Connections → Strava。
  3. 绑定后自动同步。
💡 推荐选择：如果你的目标只是"让数据进 Strava"，优先选佳明桥接——因为佳明本身还会算训练负荷、恢复时间，数据完整度最高；其次选 iGPSPORT（国内码表用户最多）；Wahoo 适合室内骑行台用户。

4.1.2 方案二：Strava API V3 实验室直传

如果你不想经过佳明/iGP/Wahoo 中转，也可以用 Strava 开放 API 直接上传。这是本软件的实验室功能，需要你自己申请一个 Strava 开发者应用。

申请步骤

  1. 浏览器访问 strava.com/settings/api，登录你的 Strava 账号。
  2. 点 Create & Manage Your App → Create New Application。
  3. 填写：
    • Application Name：随便填（如"我的同步工具"）
    • Website：随便填（如 https://localhost）
    • Authorization Callback Domain：填 localhost
  4. 创建成功后，页面会给你两个值：Client ID 和 Client Secret，复制下来。
  5. 打开本软件 → 关于页 → 实验室 → 找到 Strava，填入 Client ID / Client Secret。
  6. 点登录，跳转 Strava 授权页，点 Authorize。
  7. 授权成功后，回到本软件"数据同步设置"页，同步目标勾选 Strava。

  • Strava 开发者 API 有每 15 分钟 2000 次请求的限额，个人使用完全够。

4.2.3 Keep 接入背后的技术原理

本软件 Keep 模块（源码 KeepApi.kt）工作流程：

  1. 登录：POST https://api.gotokeep.com/v1.1/users/login，body 为手机号+密码 form 表单，返回 Bearer token。
  2. 列表：GET /pd/v3/stats/detail，分页拉取 Keep 运动记录列表。v8.5.1 修复了"Keep 同步只拉旧记录"——现在翻够 5 页/200 条才停止。
  3. 详情：GET /pd/v3/runninglog/{id}，拿单条记录详情。
  4. 轨迹解密：Keep 轨迹数据是 zlib+base64 压缩的 JSON（H4sI... 开头），解出来 geoPoints 是 AES-128-CBC 加密的。密钥 56fe59;82g:d873c，IV 2346892432920300，从 running_page 开源项目移植。
  5. 坐标转换：Keep 国内坐标是 GCJ-02，自动转 WGS-84，跨平台无偏移。
  6. 运动类型识别：自动识别 running / cycling / hiking 三类，v7.9.3 修复了"Keep 跑步被算成骑行"的 bug。
  7. GPX 写入：逐点心率（gzip 解码后按时间最近邻匹配）、逐点步频（相邻点步数差/时间差算 SPM）、海拔、卡路里，全部写入标准 GPX TrackPointExtension。
  8. 上传是半自动：Keep API 不提供上传接口，所以本软件下载后引导用户到 Keep App 内手动导入：Keep → 运动 → 数据同步 → 运动数据文件导入。
📝 Keep 桥接注意事项：
  • 绑定第三方设备后，数据同步有数分钟延迟属正常。
  • 室内运动（无 GPS 轨迹）也能同步，会生成合法 GPX。
  • Keep 不提供骑行踏频和功率数据，同步到其他平台后这两栏会空。
  • Keep 登录机会有限（纯 API 三步登录），请一次性输对手机号密码。

  • 骑行（公路/山地/室内骑行）→ manufacturer=Garmin, product=Edge 830 (3122)
  • 跑步/徒步/室内跑 → manufacturer=Garmin, product=Forerunner 945 (2967)

伪装改的是 FIT 文件 file_id 消息里的 manufacturer 和 product 字段，不改动运动数据本身。伪装后 Garmin Connect 活动详情页设备显示为 Edge 830 或 FR945，并正常计算训练负荷、VO2max、恢复时间。

5.2.4 上传 iGP 时的时区修正

历史 bug：迈金、佳明等平台的时间戳传到 iGPSPORT 国内版会差 8 小时。v9.2.2 新增 FitTimeShift.shiftForIgpsportMinus()，按用户在"时区修正"页的设置，把 FIT 文件里所有 record 的 timestamp 减 8 小时；GPX 文件走 GpxTimeFixer。v9.2.4 进一步修复 iGP 国际版上传假成功。

  • 开启后，系统每 15 分钟~1 小时自动跑一次同步。
  • 跨开机、杀进程、关 App 后仍执行（BOOT_COMPLETED 自动恢复任务）。
  • Doze 省电模式下不受影响。
  • 国产 ROM（小米/华为/OPPO/vivo）需手动把 App 加入电池优化白名单，否则后台被杀。
  • v7.5.8 修复了 Android 14+ 前台服务类型闪退。

  • 防压字：字号按画布宽度自适应，一位小数锁定不缩放，两位小数自动舍一位。
⚠️ 铁律：轨迹必须适应画面永不截断；归一化只在 HTML 端单一口径完成；预览与导出必须同源。（曾因 Kotlin/HTML 双口径归一化导致反复截断。）

第七章　FAQ：从 v1.0 到 v9.5.5 所有踩坑记录

本章把从 v1.0 到 v9.5.5 开发过程中，用户和开发者遇到的所有问题按平台分类汇总。每条标注 已解决 / 部分解决 / 未解决/平台限制。

7.1 同步通用问题

Q1：同步失败怎么办？ 已解决

看运行日志错误信息。常见原因：登录态过期→重新登录；网络问题→检查网络；平台限流→等几分钟重试。点"复制日志"发给开发者可快速定位。

Q2：为什么有些活动被跳过了？ 已解决

已同步过的活动会自动跳过（同步记忆）。想重新上传点"清记忆"。v7.5.9 起重复文件（行者 9006、Wahoo 422）统一算"跳过"不算失败。

Q3：下载的文件在哪里？ 已解决

/sdcard/Download/鸡翅幸哲迈进OB/{平台}/。

Q4：开启自动同步后闪退？ 已解决 v7.5.8

Android 14+ 前台服务类型问题。v7.5.8 用 ForegroundInfo 三参数构造函数显式指定 DATA_SYNC 类型修复。

Q5：日志显示"上传失败"但实际是重复文件？ 已解决 v7.5.9

v7.5.9 起统一归为"跳过"并自动记同步记忆。

Q6：后台同步被杀/不跑？ 部分解决

国产 ROM（小米/华为/OPPO/vivo）需要把 App 加入电池优化白名单，关闭"后台弹出限制"。App 首次启动会引导，但部分机型需要手动设置。

Q7：运行时白屏？ 已解决 v8.5.1

日志从每条刷主线程改为 200ms 批量刷新。

Q8：Fragment 重复 add 闪退？ 已解决 v8.5.4

Activity 重建时复用已恢复 Fragment，不再重复 add。

Q9：连续多选选不上？ 已解决 v8.1.3

列表事件冲突修复。

7.2 佳明（中国/国际）专题

Q10：佳明中国为什么这么慢？ 已解决 v7.9.0

原 WebView fetch 路径慢，v7.9.0 改 DI Token 直连 connectapi.garmin.cn，速度与国际区一致。

Q11：佳明经常登录不上，过一天又好？ 平台限制

佳明服务端风控：频繁登录/错误密码触发 429，冷却期数小时到一天。建议密码一次输对、勿频繁切换、勿开发版与正式版同登同一账号。

Q12：提示"所有通道触发风控限流"？ 平台限制

佳明防枚举风控。检查账号密码、是否开启两步验证，等约 24 小时再试。

Q13：两步验证(MFA)怎么关？ 已解决 v9.5.0

v9.5.0 起改 WebView 登录，直接在网页上完成 MFA。旧版本需先去 connect.garmin.com → 头像 → 账号设置 → 安全 → 两步验证 → 关闭。

Q14：佳明不计算训练负荷？ 已解决 v8.5.8

第三方 FIT 设备字段是 iGPSPORT，Garmin Connect 视为普通导入。v8.5.8 起自动伪装 Edge 830/FR945。

Q15：佳明中国批量上传失败"Required SETTINGS preface not received"？ 已解决 v7.6.0

OkHttp HTTP/2 握手不稳定。v7.6.0 起强制 HTTP/1.1 + 自动重试。

Q16：佳明中国上传 HTTP 412？ 已解决 v7.9.4

自研 FIT 补全 header。v9.4.1 进一步修复第三方 FIT 传佳明 412（file_id 消息头标志位颠倒）。

Q17：佳明国际登录 mobile SSO 第一通道就 429？ 平台限制

GCM_IOS_DARK 通道对错误密码统一返回 429 防枚举。停止尝试其他通道，等冷却。

Q18：佳明登录成功但拉不到活动？ 部分解决 v9.5.1

历史问题：DI 8 秒快速失败 + 降级 WebView fetch 30 秒超时。v9.5.1 修复协程 NoSuchMethodError/VerifyError，并加 403 自动刷新 CSRF token 重试。

第十章　小白第一次同步：手把手 15 步

如果你是第一次用这个软件，这一章按步骤照做就行。不需要理解原理，跟着点。

10.1 准备工作

  1. 下载 APK：从 GitHub Releases 或抖音群拿到最新 v9.5.5 APK，传到手机。
  2. 安装：点 APK 文件，若提示"禁止安装未知来源"，按提示去设置打开"允许此来源安装"，返回继续安装。
  3. 打开 App：看到浅蓝开屏，1 秒后弹出免责声明，点"同意并继续"。
  4. 授权：弹存储权限、通知权限，全部点"允许"。后台同步需要通知权限。

10.2 第一次登录（以 iGPSPORT → Outbase 为例）

  1. 底部 Tab 停在"登录"页。
  2. 找到 iGPSPORT 国内卡片，点一下。弹出 WebView 登录页。
  3. 在 WebView 里输入你 iGPSPORT 码表绑定的手机号和密码，登录。登录成功后会自动跳回 App，卡片变成"已登录"。
  4. 再点 Outbase 卡片，输入手机号验证码登录。
  5. （可选）如果你还想用佳明、高驰等平台，同样点卡片登录。

10.3 配置同步方向

  1. 底部 Tab 切到"同步设置"。
  2. 左侧"数据来源"选 iGPSPORT（单选）。
  3. 右侧"同步目标"勾选 Outbase（可多选）。
  4. 同步数量拉到 5（先试 5 条，别一上来 50 条）；跳过数量 0。

10.4 跑第一次同步

  1. 底部 Tab 切到"同步"，点"测试下载"。等 10 秒，日志区应该显示"✅ 下载成功，文件保存在 Download/鸡翅幸哲迈进OB/iGPSPORT/"。如果失败，看错误信息，回登录页重登。
  2. 测试下载 OK 后，点"开始同步"。等几分钟，日志会滚动显示每条活动的下载→上传。完成后统计卡片显示"成功 5、跳过 0、失败 0"。
💡 第一次成功后：回同步设置页，把同步数量拉到 20~50，打开后台自动同步。以后每次骑完车，打开 iGPSPORT 等码表同步完，本软件会自动把新记录传到 Outbase，不用再手动点。

第十三章　FAQ 补充（开发对话全过程问题）

本章补充从 v7.5 到 v9.5.5 开发对话中，用户和开发者反复讨论过的问题。每条标注状态。

13.1 登录与凭证

Q64：为什么不直接保存我的密码？ 设计如此

本软件只在登录时拿一次 token/cookie，不保存密码。token 过期自动刷新；注销时全部清除。这样即使手机丢了，别人也拿不到你的密码。

Q65：为什么佳明登录这么慢？ 平台限制

v9.5.0 起 WebView 登录要走完 mobile SSO → OAuth1 → OAuth2 → DI token 四步，网络好时 5~10 秒，网络差时 20 秒。请耐心等待，不要重复点。

Q66：Zepp 登录一次失败就再也登不上？ 平台限制

Zepp 纯 API 三步登录机会有限（防止暴力破解）。请一次性输对邮箱和密码；如果失败了，等 24 小时再试。

13.2 同步行为

Q67：为什么一条活动传了好几次？ 已解决

v7.5.9 之前，重复文件错误（行者 9006、Wahoo 422）算失败，下轮会重试。v7.5.9 起归为"跳过"并写记忆，不再重复。

Q68：同步数量设 50 但只跑了 3 条？ 正常行为

剩下 47 条已在同步记忆里。想重传点"清记忆"。

Q69：为什么迈金→iGP 时间差 8 小时？ 已解决 v9.2.2

迈金/FIT 时间戳是 UTC，iGP 国内版按北京时间解析，差 8 小时。v9.2.2 起在"时区修正"页按来源平台设 -8h。

Q70：为什么 Wahoo→iGP 上传失败？ 已解决 v9.2.6

Wahoo FIT 含 iGP 不认识的字段。v9.2.6 做了 FitSanitizer：骑行直传、仅跑步净化。

13.3 轨迹合并与贴纸

Q71：贴纸导出和预览不一致？ 已解决 v8.1.2

v8.1.2 起导出直接截预览当前帧放大，100% 一致。

Q72：贴纸导出颜色偏灰？ 已解决 v8.1.3

光晕柔化 + 颜色还原。

Q73：轨迹被截断？ 已解决

曾因 Kotlin/HTML 双口径归一化导致。现在归一化只在 HTML 端单一口径完成，预览与导出同源。

Q74：3D 是什么意思？ 设计如此

3D = 轨迹立体化（海拔 Z 轴起伏 + Yaw/Pitch 旋转 + 海拔着色），不是海拔剖面立体化。借鉴 Outbase/百度 SDK 渲染理念，纯本地 Canvas。

13.4 健康数据同步

Q75：健康同步为什么只 7 天？ 已解决 v8.7.8

v8.7.8 起任务级可输入天数（默认 7，上限 365），首次全量后增量。

Q76：419 错误？ 已解决 v8.7.8

18.3 为什么用 WebView 登录

很多平台（iGPSPORT/行者/迈金/黑鸟/佳明/高驰）的登录页有滑块验证、人机验证、Cloudflare 挑战，纯 API 模拟很容易被封。用 WebView 让用户在真实网页里登录，登录成功后从 cookie/localStorage 里提取 token，既稳定又不违反平台 ToS（用户自己输密码）。

18.4 为什么 Keep 是纯 API

Keep 登录没有滑块验证，纯 form POST 就能拿到 token，不需要 WebView。轨迹解密逻辑（zlib+AES）从 running_page 开源项目移植。

18.5 为什么后台同步用 WorkManager

Android 原生 Service 在国产 ROM（小米/华为/OPPO/vivo）上经常被一键杀掉。WorkManager 是 Jetpack 组件，系统级调度，跨开机恢复，Doze 模式下仍执行，最稳定。

第二十五章　FAQ 补充（更多细节）

Q81：本软件要付费吗？ 免费

完全免费。赞赏是自愿赠与，不构成服务合同。

Q82：为什么没有 iOS 版？ 未计划

个人开发者，Android 技术栈。iOS 沙盒限制多，暂不计划。

Q83：为什么没有 Windows/Mac 版？ 未计划

手机端场景为主。如果你需要桌面端，可以用 running_page 等开源项目。

Q84：同步会消耗多少流量？ 说明

一条 FIT 文件约 100KB~1MB。同步 50 条约 5~50MB。建议 WiFi 下跑全量，移动网络下跑增量。

Q85：同步会耗电吗？ 说明

后台同步每 15 分钟跑一次，每次几秒到几十秒，耗电可忽略。

Q86：为什么同步时手机发烫？ 已知

迈金坐标转换在 WebView 里跑 JS，CPU 短时高负载。跑完即恢复。

Q87：为什么下载的 FIT 文件打不开？ 说明

FIT 是二进制格式，手机文件管理器打不开。用本软件的"记录中心"看，或传到平台后在平台网页看。

Q88：为什么 Outbase 上传后活动详情是空的？ 平台限制

Outbase 对某些来源的 GPX 解析不完整。建议来源选 iGP/迈金/黑鸟等 FIT 源。

Q89：为什么同步后海拔不对？ 平台限制

码表 GPS 海拔 vs 气压计海拔差异。黑鸟平台自身问题。

Q90：为什么功率数据偏小？ 平台限制

黑鸟平台 ×0.78 校准。本软件不修改原始功率数据。

Q91：为什么卡路里不对？ 平台限制

各平台卡路里算法不同，本软件保留原始值，不重算。

Q92：为什么平均速度不对？ 平台限制

各平台均速算法不同（有的含红灯停车，有的不含）。本软件保留原始值。

Q93：可以同时跑多个同步任务吗？ 支持

可以。本软件支持多任务，每个任务独立来源/目标。

Q94：同步时可以关屏吗？ 可以

可以。WorkManager 后台跑，关屏不影响。但国产 ROM 需加电池白名单。

Q95：同步时可以切到别的 App 吗？ 可以

可以。同步在后台跑，前台通知显示进度。

Q96：同步中途断网会怎样？ 说明

当前这条失败，下轮重试。已成功的写记忆，不重传。

Q97：同步中途杀进程会怎样？ 说明

当前这条中断，下次启动自动重试。已写记忆的不重传。

Q98：为什么"清记忆"后所有活动都重传？ 设计如此

清记忆就是删小本本，下次同步全量重传。谨慎使用。

Q99：为什么实验室平台登录不稳定？ 平台限制

实验室平台（Suunto/Zepp/Strava 等）接口不稳定或需自申请凭证，所以放实验室页灰度。

Q100：本软件会上传我的运动数据到自己服务器吗？ 不会

本软件没有后端服务器。所有同步在你手机和各平台之间直连。

## 4. 本轮 Strava 链路四次修正（按发现顺序）

| 轮次 | 问题 | 改法 |
|---|---|---|
| fix3 | 网页登录回传被送进 OAuth 兑换（守卫助记符写反 + `$1$3` 兑换路径） | `loginLauncher` 加硬闸门：`type` 以 `strava` 开头 → 只存 cookie；`$1$3` 二次兜底直接返回 |
| fix5 | 登录成功但 cookie 未被保存 | `saveStravaCookie` 落 prefs（key `strava_cookie`），成功后打印字节数；真机实测 2438 / 2474 / 2428 B |
| fix6/7 | 上传侧把 credential 当标题、又另读 prefs；内存态与 prefs 不一致 | 新增静态副本 `fix3StravaCookie`；`getCredential(DataSource)` 加 STRAVA 分支；`uploadToStravaWeb` 改「凭证优先、空则读 prefs」 |
| fix8 | 四处长度/空值判定极性与 Dalvik 助记符语义相反（`if-nez` = 不为 0 才跳），导致「cookie 非空 → 未登录」 | `getStravaCookie`、`isStravaWebLoggedIn`、`uploadToStravaWeb` 两处判定统一改为 `if-eqz`；清除全部诊断桩与构造期自测写入 |

**根因判定**：`isLoggedIn(STRAVA)` 走的是 `isStravaWebLoggedIn()`，而高驰等平台走各自的 token/字段非空判定，不经过该函数——因此只有 Strava 表现为「永远未登录」，其它平台不受影响。
